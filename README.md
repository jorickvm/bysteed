# bysteed.com

Source for [bysteed.com](https://bysteed.com), the home of Apps by Steed: a landing page for the apps, with localized product, privacy and support pages for Shift and Stallion.

Static HTML and CSS published with GitHub Pages. There is no build step.

## Layout

```
index.html   landing page
shift/       Shift product, privacy and support pages, per language
stallion/    Stallion product, privacy and support pages, per language
assets/      shared scripts, app icons, brand marks and link previews
scripts/     sitemap and link-preview tooling
```

Shift's product pages are generated by `scripts/build_product_pages.py` in the
Shift repository and committed here. Store languages use App Store metadata
and localized artwork; app-only languages use dedicated website translations
and existing app copy. Those pages reuse English screenshots with translated
descriptions and a language note until localized artwork is available.
Privacy and support links use an existing translation or explicitly link to
the English page. The other pages are written by hand.

Regenerate from the Shift checkout, passing `--website-root /path/to/bysteed`
when working in separate checkouts; `--check` detects stale pages. Then rebuild
the sitemap here. No generated page should be edited directly.

## Local preview

```bash
python3 -m http.server 8898
```

## Sitemap

```bash
python3 scripts/build_sitemap.py           # rewrite sitemap.xml
python3 scripts/build_sitemap.py --check   # fail if sitemap.xml is out of date
```
